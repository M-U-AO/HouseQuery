# 一期需求边界

## 纳入

- 石景山区当前两页共 17 条住宅预售项目。
- 首页总览：预售项目数、楼栋数、可售数、本次变化、新增项目。
- 首页变化：各项目组成交数量、变化量、最近变化、最近 7 次快照趋势。
- 项目组详情：预售项目列表、楼栋概览、状态汇总、本次变化。
- 楼栋详情：按住建委颜色展示每户房号和状态。
- 本地 SQLite 持久化，数据保存在当前项目目录 `data/app.db`。
- 全量成功才生成成功快照；失败时使用上一次成功数据并提示失败。

## 暂不纳入

- 额外车库和非住宅预售证深度分析。
- 用户手动创建或编辑项目组。
- 任意两次历史快照对比。
- 房源详情页点击进入。
- 登录、权限、局域网部署、小程序上线。

## 后续可能扩展

- 新增预售证作为新增房源或新增项目提示。
- 全北京期房项目监控。
- 局域网访问、云端部署或小程序前端。
- 历史快照查询与任意两次对比。
